 Number Guessing Game

 1. Project Title
Number Guessing Game

 2. Overview of the Project
The Number Guessing Game is a simple Python console-based game. The computer generates a random number between 1 and 100, and the player tries to guess it. After each incorrect guess, the game gives a hint to choose a higher or lower number.

The game provides three difficulty levels: Easy, Medium, and Hard.

 3. Features
- Easy Level: Unlimited guesses until the player guesses correctly.
- Medium Level: A maximum of 10 chances.
- Hard Level: A maximum of 5 chances.
- Gives a hint to guess higher or lower after an incorrect guess.
- Displays a winning message when the correct number is guessed.
- Allows the player to play again.

 4. Technologies/Tools Used
- Programming Language: Python 3
- Module: `random`
- Code Editor: Visual Studio Code or any Python-compatible editor
- Python concepts: Functions, `while` loops, `if-elif-else` statements, user input, `break`, and `return`

 5. Steps to Install and Run the Project
1. Install Python 3 from https://www.python.org/downloads/.
2. Open Visual Studio Code or another code editor.
3. Copy the project code into a new file.
4. Save the file as `number_guessing_game.py`.
5. Open the terminal in the folder where the file is saved.
6. Select a difficulty level by entering `1`, `2`, or `3`.

 6. Instructions for Testing
1. Run the program.
2. Enter `1` to test Easy mode, `2` to test Medium mode, or `3` to test Hard mode.
3. Enter a number between 1 and 100 when prompted.
4. Check that a guess below the secret number produces a hint to choose a higher number.
5. Check that a guess above the secret number produces a hint to choose a lower number.
6. Enter the correct number to check that the winning message appears.
7. In Medium mode, make 10 incorrect guesses to test the attempt limit.
8. In Hard mode, make 5 incorrect guesses to test the attempt limit.
9. At the replay prompt, enter `yes` to test replay or `no` to test exiting.
