 Number Guessing Game — Statement

 1. Problem Statement
Beginners need a simple and interactive way to practise basic Python programming concepts. This project addresses that need through a number guessing game in which the computer selects a random number and the player tries to guess it. The program provides higher-or-lower hints and uses different attempt limits depending on the selected difficulty level.

 2. Scope of the Project
The project covers a text-based game that runs in a Python console. It generates a random number from 1 to 100, accepts the player's guesses, checks each guess, and displays helpful hints. It includes Easy, Medium, and Hard difficulty levels, with unlimited guesses in Easy mode, 10 chances in Medium mode, and 5 chances in Hard mode. The project also includes a replay option.

The current scope does not include a graphical interface, online multiplayer, or a saved high-score system.

 3. Target Users
- Students learning the basics of Python programming.
- Beginners who want to practise functions, loops, and conditional statements.
- Users who enjoy simple number-based games.

 4. High-Level Features
- Random number generation: The computer selects a secret number between 1 and 100.
- Three difficulty levels: Easy, Medium, and Hard.
- Guess feedback: The game tells the player to guess higher or lower after an incorrect guess.
- Limited attempts: Medium mode allows 10 chances and Hard mode allows 5 chances.
- Win message: The game congratulates the player for guessing correctly.
- Replay option: The player can choose whether to play again.
